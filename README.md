# MIT Maker Portfolio
Codebase for Brian Yang's MIT Maker portfolio.

# Repository Setup

The build prompts I used to create the Chronocounter mobile app is included in the root directory. To view the version-controlled development process for the app, check out https://github.com/bbrb546/chronocounter_app. The Godot project is copied here in godot/.

The six scripts that make up the server are located in scripts/server/, and various tools I used to format datasets are in scripts/other/dataset_tools. Unused alternate versions of algorithm1 (line grouping) and algorithm2 (long rest processing respectively) can be found in scripts/other/unused_scripts/.

The Biology visual novel project is located in non_chronocounter/bio_visual_novel/ and the Papers Please immune system project is located in non_chronocounter/bio_papers_pleaes/. The automatic linear equation solver is non_chronocounter/autosolvelinear.py.
